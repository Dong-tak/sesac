# TTNet 탁구 분석 실습

TTNet을 이용해 탁구공 위치와 바운드·네트 이벤트를 학습하고 웹캠으로 시험한 실습 코드입니다. 원본 코드의 저자 표기를 유지했습니다. 참고 구현: https://github.com/maudzung/TTNet-Realtime-for-Table-Tennis-Pytorch

`prepare_dataset/`은 OpenTTGames 데이터 다운로드와 학습 프레임 준비, `src/`는 모델·학습·평가·웹캠 실행, `tests/`는 손실 함수와 경기 분리 검사를 담습니다. 학습과 검증 경기는 분리했습니다. 진행 내역과 성능의 한계는 [학습 진행상황](학습_진행상황.md)을 참고하세요.

데이터셋, 로컬 가상환경, 체크포인트 및 학습 산출물은 이 저장소에 포함하지 않습니다. 웹캠 실행에는 별도로 설치한 의존성과 신뢰할 수 있는 로컬 체크포인트가 필요합니다. 현재 모델은 바운드·네트 구분 성능이 부족하고 선수별 득점 판정은 구현되지 않았습니다.
