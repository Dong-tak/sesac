# 01 · Python 기초

기존 `sesac3` 폴더의 Python 시작 코드와 Jupyter 노트북을 보관합니다.

## 파일

- `main.py`: `hello world`를 출력하는 시작 예제
- `sesac.ipynb`: 기존 실습 노트북

## 실행

저장소 루트에서 다음과 같이 실행합니다.

```powershell
cd 01-python-basics
python main.py
```

노트북은 VS Code의 Jupyter 기능이나 설치된 Jupyter에서 열면 됩니다. 이 정리 작업에서 노트북 셀을 실행하거나 내용을 수정하지 않았습니다.
